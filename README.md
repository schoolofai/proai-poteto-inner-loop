# Harbor Desk

A tiny folder sidebar. This is a private local starter for a ProAI Clips experiment. Do not publish or push it until the owner says so.

## Tags

- `step-0-slop` — seeded quick-fix timers and an untested sidebar path.
- `step-1-inner-loop` — root-cause fix, behavior tests, and `npm run verify`.

## Commands

```bash
npm install
npm run dev
npm test
npm run verify
```

`npm run verify` runs the timer check, lint, typecheck, tests, and the production build.

Part 1 notes, sources, install steps for pstack, and the spike transcripts are in [docs/part-1-inner-loop.md](docs/part-1-inner-loop.md).
